## 🎯 Quick Start Guide

### Installation (5 Steps)

```bash
# 1. Install Python packages
pip install -r requirements.txt

# 2. Install TA-Lib (platform-specific)
# Windows: Download .whl from lfd.uci.edu
# macOS: brew install ta-lib && pip install TA-Lib
# Linux: See INSTALL_GUIDE_KR.md for full instructions

# 3. Verify installation
python test_imports.py

# 4. Configure API keys
cp config.example.json config.json
nano config.json  # Add Binance & OpenAI keys

# 5. Run!
python main.py
```

### Usage (4 Steps)

1. **Press ENGAGE** - Start system
2. **Watch Status Lights** - ●API ●DATA ●AI (all green = healthy)
3. **Select Timeframe** - Click [1m] to [4h] to match your chart
4. **Monitor Signals** - Log shows analysis, voice alerts on signals

**Emergency:** Press SPACEBAR anytime for instant stop!

## 💡 Best Practices

### For Beginners
1. Start with **testnet** (config: `"testnet": true`)
2. Use **15m or 30m** timeframe (balanced)
3. Observe for **2-3 days** before live trading
4. **Never risk** more than 1-2% per trade
5. Always **verify signals** manually
6. Keep **panic button** ready (SPACEBAR)
