# 🚀 22-Billion 시작하기

## 빠른 시작 (3단계)

### 1️⃣ 설치
```bash
pip install -r requirements.txt
```

**TA-Lib 설치** (플랫폼별):
- **Windows**: [가이드 보기](INSTALL_GUIDE_KR.md)
- **macOS**: `brew install ta-lib && pip install TA-Lib`
- **Linux**: [가이드 보기](INSTALL_GUIDE_KR.md)

### 2️⃣ 설정
```bash
cp config.example.json config.json
nano config.json  # API 키 입력
```

**필수 API 키:**
- Binance: https://testnet.binancefuture.com (무료 테스트넷)
- OpenAI: https://platform.openai.com/api-keys

### 3️⃣ 실행
```bash
python main.py
```

**GUI에서:**
1. **ENGAGE** 버튼 클릭
2. 상태등 확인: ●API ●DATA ●AI
3. 신호 모니터링
4. **스페이스바** = 긴급 정지
