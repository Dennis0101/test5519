### Setup (One Time)
1. Install dependencies: `pip install -r requirements.txt`
2. Install TA-Lib (see guides)
3. Create `config.json` from template
4. Add API keys (testnet recommended)

1. Run: `python main.py`
2. Press: **ENGAGE** button
3. Watch: Status lights (●●●)
4. Monitor: Log for signals

- Never risk >1-2% per trade

- Trust the system but verify signals
